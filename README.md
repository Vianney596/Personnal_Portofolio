# Vianney's Portfolio

Personal portfolio website presenting my projects, skills, and background as a software student based in Cotonou, Benin.


## About

I'm a Computer Science student (Networks & Software Architecture) at ESGIS Cotonou, currently looking for a technical internship in the Cotonou area. This portfolio showcases the projects I've built through coursework, group work, and personal initiatives.

## Sections

- **Home**: introduction and overview
- **Projects**: selected work with descriptions and links
- **Skills**: languages, frameworks, and tools I use
- **Contact**: how to reach me

## Built with

- HTML5
- CSS3
- JavaScript


## Run locally

```bash
git clone https://github.com/vianney596/Personnal_Portofolio.git
cd Personnal_Portofolio
```

Then open `index.html` in your browser, or use a local server such as the VS Code "Live Server" extension.

## Deployment

The site is hosted on GitHub Pages and deployed automatically from the `main` branch (root folder) on every push.
